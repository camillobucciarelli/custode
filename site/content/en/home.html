Open source password manager

Your passwords, in a file that stays yours.

Custode keeps your vault in the open KeePass .kdbx format, on your own devices. No account, no server of ours, no telemetry.

The file is yours

The vault is an ordinary .kdbx file. You open it with Custode or with any KeePass-compatible app: if you change your mind one day, you take everything with you.

No account

There is nothing to sign up for. No ads, usage analytics or automatic error reports: the app works without a network too.

Open code

All the code is public on GitHub under the AGPL-3.0 licence, browser extension included. You can read it, build it and verify it.

Sync

On all your devices, with your own Google Drive.

If you want, Custode keeps the vault aligned through your Google Drive space. It uploads only the encrypted file: the master password never leaves the device.

  • If two devices changed the vault, Custode asks which version to keep, or lets you review field by field.
  • Before replacing a file, Custode saves a copy of it.
  • Optional: without sync the app contacts no one.

Vault health

Know which passwords to change.

Custode checks the vault on the device and points out weak, reused, old or duplicate passwords. With the generator you create a new one in one tap.

And the rest you would expect.

One-time codes

Add the two-factor code to an entry by scanning the QR code on Android, iPhone and iPad, or by pasting the otpauth:// address on a computer. Custode generates the code next to the password.

Password generator

Long, random passwords, with the rules you choose, right while you create or edit an entry.

Unlock with biometrics or a key file

Open the vault with the master password, with fingerprint or face, and with a key file if you use one.

Protected custom fields

Add the fields you need to an entry and mark as secret the ones to keep hidden.

Import

Bring your passwords from Bitwarden, 1Password, LastPass, Chrome or Apple Passwords with a CSV file, or open a KeePass vault you already have.

Auto-lock

The vault locks after a period of inactivity and the clipboard clears 30 seconds after a copy.

Security

What leaves your device: almost nothing.

We would rather tell you precisely what the app does, and also what we cannot promise you yet.

Custode has never had an independent security audit. The code is public precisely so that anyone can examine it. Read the security model

Encrypted vault
The KDBX file is encrypted with a key derived from your master password, which is never transmitted.
Secrets in the system keychain
The data for biometric unlock and Google sign-in stay in the operating system’s secure storage.
Network only when you ask for it
Google Drive if you turn on sync; the update check is off until you switch it on.
No data about you
No account, telemetry, usage analytics, automatic error reporting or ads.
