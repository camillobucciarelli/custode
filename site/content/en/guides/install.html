Custode runs on phone, tablet and computer. Pick your device, install the app and open it: the first screen takes you to your vault.

All platforms5 minutes

Before you start

Everything starts from the download page. Android also has an APK you can install right away. On iPhone, iPad and Mac the app is for now in testing with TestFlight, so you ask for access first. Google Play, the App Store and the Mac App Store are not available yet.

Android

  1. Download the APK

    On the download page, under Android, choose Download the APK.

  2. Allow the installation

    When Android asks, allow your browser to install apps, then open the downloaded file and confirm.

  3. Open Custode

    Start the app from the list of your apps.

If you prefer Google Play, the app is in testing there: on the download page choose Ask for test access and you can ask to take part.

iPhone, iPad and Mac

  1. Ask for access

    On the download page choose Ask for test access under iPhone and iPad, or under Mac. It prepares an email with the platform already filled in: add the email of your Apple ID and send it.

  2. Accept the invitation

    You receive an invitation to install the app with TestFlight. Follow it and install Custode.

Windows and Linux

  1. Download the ZIP

    On the download page choose Download the ZIP under Windows or Linux.

  2. Extract it

    Extract the whole ZIP into a folder of your choice.

  3. Run the app

    From the extracted folder run password_manager.exe on Windows or password_manager on Linux.

Chrome and Edge extension

The extension fills in sign-in forms on your computer and works together with the app for Mac, Windows or Linux, so install the app first. Then open the Chrome Web Store from the download page, under Chrome and Edge, and add the extension.

Download only from this site. Use the links on the download page, which always point to the latest version. Earlier versions are listed on GitHub.
