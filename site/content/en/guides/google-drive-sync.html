Connect your Google account to have the same vault on all your devices. Custode uploads only the encrypted .kdbx file, to your own Drive space.

All platforms5 minutes

Before you start

You need a vault already open in Custode and a Google account. Sync is optional: you can unlink it whenever you want and the file stays on the device.

Link the vault

  1. Open the vault and go to sync

    Unlock the vault, then open Sync: on a phone it is a tab in the bottom bar, on a computer it is the icon with the two arrows in the sidebar.

  2. Choose Google Drive

    You find it under Choose a provider. The Google sign-in page opens: sign in and allow Custode to use your Drive.

  3. Link a file

    Under Link a file choose Create a new file on Google Drive to upload the vault to the top folder of your Drive, or Pick an existing .kdbx to link one that is already there, for example the one uploaded from another device.

  4. Run the first sync

    Tap Sync now, the round button with the two arrows. Auto-sync is already on: Custode syncs by itself a few seconds after each change. If you prefer to do it by hand, turn it off on the same screen.

If a conflict appears

It happens when the same vault was changed on two devices before syncing. Custode does not choose for you: it shows Both versions changed and asks what to keep.

Keep local
Keeps the version on this device and uploads it to Drive.
Use remote
Replaces the local file with the one on Drive, after saving a copy of it.
Review field by field
Opens the comparison of the two versions, to decide field by field.
Cancel
Changes nothing: you can check calmly and try again.

What Google sees. The encrypted file and its name. The master password does not leave the device and the content of the vault travels only encrypted.
