A vault is one .kdbx file that holds all your passwords, protected by a master password, a key file or both. You can create a new one or open a KeePass file you already have.

All platforms5 minutes

Before you start

Have Custode installed. To open an existing vault you need its .kdbx file on the device, and its master password or key file.

Create a new vault

On the first start the welcome screen shows Create new database. If you already have a vault, the same action is in the Databases list, among the options to add one.

  1. Name the file

    Under Name your database (Step 1 of 2) type the name in Database file name. The characters \ / : * ? " < > | are not allowed. Then choose Continue.

  2. Choose how to protect it

    Under Choose your credentials (Step 2 of 2) you can use a master password, a key file, or both. You need at least one: until you set it, the screen says so and Create stays off.

  3. Set a master password

    Type it in Master Password (optional). A strength indicator shows Weak, Fair, Good or Strong, and a second field, Confirm Password, asks you to type it again.

  4. Add a key file, if you want one

    Under Key File choose one option: No key file, Select an existing file to use a file you already have, or Generate automatically to let Custode make one.

  5. Decide on biometrics

    The Enable biometric protection switch is off by default. Turn it on if you want to unlock with fingerprint or face. It needs a master password: without one, Custode asks you to set a password or turn the switch off. More in Unlock with biometrics or a key file.

  6. Create the vault

    Choose Create. Custode then shows the unlock screen of the new vault: enter your credentials to open it.

Keep a copy of the key file. If you generate it, Custode warns you: losing the key file makes the database inaccessible. The vault is saved in the app's own storage, so export a backup now and then: if you delete Custode without one, the file goes with it. You find the exports in Settings, under Backups & import: Export the database and Export the key file.

Open a vault you already have

  1. Choose Open existing database

    It is on the welcome screen, or in the Databases list. The file picker shows only .kdbx files: pick yours.

  2. Unlock it

    Custode keeps its own copy of the file in the app's storage and opens the unlock screen. Enter the master password, or choose Use a key file if the vault has one.

Some messages you may see:

Replace existing database?
A database with that name is already in the app. Replace overwrites it with the file you picked, otherwise cancel.
Duplicate database detected
You picked a file that matches one already in the app. Choose Keep both to save it as another database, Replace existing to back up and replace the old one, or Use existing to open the one you have.
Invalid database file
The file is not a valid Custode database. Check that you picked the right .kdbx.
Database file is corrupted
The file could not be read and may be damaged. Try a backup copy.

A vault in Google Drive

If the vault is on Google Drive, choose Open from Google Drive instead, sign in and pick the file. Custode then offers to require biometric authentication for it. To keep it in step across devices, see Sync with Google Drive.
