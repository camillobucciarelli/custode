Your vault is a single .kdbx file. Export a copy of it from time to time and keep it somewhere else: if you lose the device, that copy is your vault.

All platforms3 minutes

Export a copy

  1. Open Settings and choose Backups & import

    With the vault unlocked. You find it in the Database group.

  2. Choose Export the database

    The system asks where to save the file. Pick a place outside the device if you can, for example a USB drive.

  3. Wait for the confirmation

    Custode shows Database backup exported. The copy is the same encrypted file: it opens with the master password the vault had at the moment you exported it.

  4. If you use a key file, export that too

    Choose Export the key file. Without the key file the copy of the vault cannot be opened. As the app says, keep it apart from the database: not in the same place as the vault copy.

Restore a copy

  1. Go to the list of vaults

    It is the first screen of the app. If a vault is open, go to Settings and choose the Close database button next to the Database title. The app asks you to confirm and warns that the credentials saved for that vault on this device are removed: have the master password at hand.

  2. Choose Open existing database

    Pick the .kdbx copy you exported.

  3. Unlock it

    Enter the master password and, if the vault had one, choose the key file with Use a key file.

On a phone or tablet

The app keeps its own copy of the file you open. If a vault with the same file name is already there, Custode asks Replace existing database?: with Replace the one in the app is overwritten by the copy you are opening.

On a phone the vault lives inside the app. If you delete Custode without a backup, the file goes with it. Export a copy before you uninstall the app or change phone.
