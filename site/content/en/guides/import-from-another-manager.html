Bring your passwords into Custode from a CSV file exported by Bitwarden, LastPass or Chrome, or open a KeePass .kdbx vault you already have.

All platforms10 minutes

Before you start

CSV import works inside a vault that is already open, so create or open one first. Then export your passwords from the other app as a CSV file, using its own export option, and keep the file on the device where Custode runs.

Import a CSV file

  1. Open the import

    Unlock the vault, open Settings, then Backups & import and choose Import from CSV. Pick the .csv file in the file picker.

  2. Check the preview

    The Import CSV screen shows the file, the Detected format (Bitwarden, LastPass, Chrome, 1Password, Apple Passwords or Generic CSV) and three counts: Rows found, Valid records and Skipped rows.

  3. Decide about duplicates

    Avoid duplicates is on by default: it skips rows that match a record already in this vault, comparing title, username and URL. Turn it off only if you want every row added.

  4. Import

    Choose Import followed by the number of valid records, or Cancel to stop with nothing changed.

  5. Read the result

    Import finished tells you how many records were added and how many were skipped as duplicates. Rows that could not be read are listed with the reason. Choose Done to close it.

What is imported

Title, username, password, URL, notes
Read from the columns of the file, whichever of the known formats it comes from.
One-time codes
A column holding an otpauth:// link is kept as a field named otp on the entry.
Other columns
Any other column with a value is kept as a custom field named like the column. Folders are not recreated: a folder column is kept the same way, as a field.
Not imported
The type, favorite, fav and reprompt columns, rows with nothing in title, username, password, URL and notes, and any passkey column: a passkey is created in the app, on the site that asks for it. The result screen lists them.

Delete the CSV afterwards. It holds your passwords in clear text, as Custode reminds you on the preview screen. Empty the trash or recycle bin as well, and remove it from the other app's downloads.

Open a KeePass vault

A .kdbx file from KeePass or another KeePass-compatible app does not need importing: it is already in the format Custode uses. Choose Open existing database and pick the file, then unlock it with its own master password or key file. The steps are in Create your first vault.

Opening a .kdbx adds it to Custode as a separate vault. The app has no option to merge one vault into another: to move entries between them you need a CSV.
