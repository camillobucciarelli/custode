A browser extension lets you fill logins from the Custode app on your computer into the page you have open. The extension holds no passwords: it asks the app, and only when you choose an entry.

macOS, Windows, Linux10 minutes

Before you start

You need Custode installed on the computer, with a vault unlocked and the app left open: the extension talks only to the running app. You also need Chrome, or Edge on a Mac. Firefox is not supported.

Set it up

The setup screen in the app is in Italian, so the labels below are shown as they appear.

  1. Open the setup screen

    In Custode open Settings and choose Autofill & browsers. The screen Estensione browser desktop opens, with three numbered steps.

  2. Install the extension

    Under Installa l’estensione choose Apri Chrome Web Store and add Custode Browser Autofill to the browser.

  3. Connect the browser to Custode

    Under Collega Chrome a Custode the action depends on your computer; see the list below. When it is done, restart the browser.

  4. Check the connection

    With the vault unlocked, under Verifica la connessione choose Verifica. When the app is ready you read Custode è pronto per collegarsi all’estensione Chrome.

  5. Open the extension

    Click the Custode icon in the browser toolbar. The popup Custode Autofill shows two boxes: Native host should read Connected and App / vault bridge should read Unlocked.

Step 3 on each system

macOS
Choose Scarica Chrome Support. A signed package is downloaded: open it, complete the installation and restart the browser. The package connects both Chrome and Edge.
Windows and Linux
Choose Configura Chrome. Custode sets up the connection for Chrome by itself and confirms with Chrome configurato. Riavvia Chrome e verifica la connessione.
Windows, Microsoft Store version
This version cannot create the connection, and the button reads Apri le release GitHub. Download the Custode zip from the release page, start that version and repeat step 3 from there.

Fill a login

  1. Open the popup on the login page

    Click the Custode icon. Under Matches you find the entries saved for that exact site.

  2. Choose Fill

    The username and password are written into the page. The password is asked from the app at that moment and is not stored by the extension.

  3. Search if nothing matches

    Use the field Search title, user, service. Entries listed under Possible have the button Ask app instead of Fill: it saves a link between the entry and the site, which you confirm in the Custode app.

Suggestions inside the page

The extension can also show a suggestion box next to the login field, without opening the popup. It is off by default.

  1. Turn it on from the popup

    Next to In-page autofill overlay choose Turn on. The browser asks you to allow access to all http and https sites: the box has to be placed in the page, and the browser cannot grant this one site at a time.

  2. Use it on a login page

    The box lists only the entries saved in your vault for that exact site. The extension does not read the content of the pages.

  3. Turn it off when you want

    Turn off in the same place also gives the permission back. If you decline the browser request, nothing is turned on.

Check the connection status

In the popup
Native host tells you whether the browser reaches Custode on this computer; App / vault bridge tells you whether the vault is unlocked.
In the app
In Settings, the row Autofill & browsers shows Browser extension connected, Browser extension not set up or Browser helper not reachable.

If it does not work

  • Native host reads Not found: the connection is missing for this browser. Repeat step 3, restart the browser and choose Check again.
  • App / vault bridge reads Locked: unlock the vault in the app, then choose Refresh status.
  • The app shows Sblocca il vault in Custode e riprova.: unlock the vault and choose Verifica again.
  • The app shows Bridge non raggiungibile. or Collegamento non disponibile.: restart Custode, or lock and unlock the vault, then check again.
  • An entry shows Open Custode instead of Fill: it cannot be filled on this page. Copy the login from the app.
  • Still stuck: on the setup screen open Diagnostica collegamento. The rest of Custode keeps working; only filling in the browser is missing.
