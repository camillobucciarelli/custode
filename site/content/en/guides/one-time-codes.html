Keep the two-factor code of a site in the same entry as its password. Custode shows the current code and how many seconds it has left.

All platforms3 minutes

Before you start

Open the two-factor setup page of the site, the one that shows a QR code. Custode works with time-based codes and needs the whole setup address, the one that starts with otpauth://. The QR code contains it; many sites also let you copy it as text.

Add the code to an entry

  1. Open the entry and choose Edit

    For a new entry, choose Add record in the vault instead.

  2. Under Optional, choose One-time code

    The field OTP URI (otpauth://…) appears.

  3. Scan the QR code or paste the address

    On Android, iPhone and iPad, tap Scan QR inside the field and point the camera at the QR code shown by the site. On a computer there is no scanner: paste the address that starts with otpauth:// into the field.

  4. Choose Save

    It is the round button with the check mark at the top.

Read and copy the code

  1. Open the entry

    The One-time code row shows the current code. The circle next to it counts the seconds left before the code changes.

  2. Choose Copy

    Custode confirms with Copied one-time code. and empties the clipboard about 30 seconds later, if it still holds the code.

If the scan does not work

Camera is off for Custode
Custode has no permission to use the camera. Choose Open system settings and allow it, or paste the address into the field on that screen and choose Save the URI.
QR does not contain a valid OTP URI.
The QR code you scanned is not a two-factor setup code. Scan the one on the site’s two-factor setup page.
OTP URI must start with otpauth://
You pasted only the secret key, or another piece of text. Paste the whole address.
