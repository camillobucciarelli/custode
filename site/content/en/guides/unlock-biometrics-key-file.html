Every time you open a vault, Custode asks you to unlock it. You can type the master password, use a key file, or let your fingerprint or face do it for you.

All platforms3 minutes

Before you start

The credentials a vault accepts are the ones chosen when it was created or later changed in Settings: a master password, a key file, or both. For biometrics your device must have fingerprint or face unlock set up.

Unlock with the master password

  1. Type the password

    On the unlock screen, which shows the vault name, type it in Master password. The eye icon (Show password) lets you check what you typed.

  2. Unlock

    Choose Unlock vault. While it works Custode shows Decrypting and the vault name: it can take a moment.

If the password or the key file is wrong, the field shows Incorrect master password or key file. and you can try again.

Unlock with a key file

  1. Choose Use a key file

    It is the link under the unlock button. If your device has a screen lock, Custode first asks you to authenticate: it protects the key files kept in the app.

  2. Import or select the key file

    The Internal key files list shows the key files stored in the app. If yours is not there, choose Import and pick the file from your device, then choose Select next to it.

  3. Unlock

    The selected file appears under the password field, with Remove key file to take it away. The button now reads Unlock with key file. If the vault uses only the key file, leave the password empty: it is Optional while a key file is selected. If it uses both, type the password too.

Custode remembers which key file a vault uses. If the file is no longer there it says Key file not found. Locate or select the required key file. and you can choose it again.

Unlock with biometrics

  1. Turn it on

    When you create a vault, use the Enable biometric protection switch. For a vault you already use, unlock it, open Settings and turn on Biometric protection. It needs a master password, which Custode keeps in the device's secure storage for this purpose.

  2. Authenticate

    The next time you open the vault Custode shows Authenticate with biometrics and asks for your fingerprint or face. If it works, the vault opens by itself.

  3. If it does not work

    Choose Retry to try again, or Use master password instead to type the password this time. Biometrics will be asked again the next time you open the vault.

To switch it off, turn off Biometric protection in Settings: the stored password is deleted from the device. If biometrics are not available on the device, Custode says Biometric authentication is not available on this device. and shows the normal form.

No recovery. Custode has no account and no "forgot password" option. Without the master password, or the key file, the vault cannot be opened, and a generated key file is not recoverable if you lose it. Keep both safe, and export the key file apart from the database: in Settings, Backups & import, Export the key file.
