Prima di iniziare

Ti servono un archivio già aperto in Custode e un account Google. La sincronizzazione è facoltativa: puoi scollegarla quando vuoi e il file resta sul dispositivo.

Collegare l’archivio

  1. Apri l’archivio e vai alla sincronizzazione

    Sblocca l’archivio, poi apri Sync: sul telefono è una scheda nella barra in basso, sul computer è l’icona con le due frecce nella barra laterale.

  2. Scegli Google Drive

    Lo trovi sotto Choose a provider. Si apre la pagina di accesso di Google: accedi e consenti a Custode di usare il tuo Drive.

  3. Collega un file

    Sotto Link a file scegli Create a new file on Google Drive per caricare l’archivio nella cartella principale del tuo Drive, oppure Pick an existing .kdbx per collegarne uno che c’è già, per esempio quello caricato da un altro dispositivo.

  4. Avvia la prima sincronizzazione

    Tocca Sync now, il pulsante rotondo con le due frecce. Auto-sync è già attivo: Custode sincronizza da sola pochi secondi dopo ogni modifica. Se preferisci farlo a mano, spegnilo dalla stessa schermata.

Se compare un conflitto

Succede quando lo stesso archivio è stato modificato su due dispositivi prima di sincronizzare. Custode non sceglie al posto tuo: mostra Both versions changed e ti chiede cosa tenere.

Keep local
Tiene la versione di questo dispositivo e la carica su Drive.
Use remote
Sostituisce il file locale con quello su Drive, dopo averne salvato una copia.
Review field by field
Apre il confronto tra le due versioni, per decidere campo per campo.
Cancel
Non cambia niente: puoi controllare con calma e riprovare.

Cosa vede Google. Il file cifrato e il suo nome. La password principale non lascia il dispositivo e il contenuto dell’archivio viaggia soltanto cifrato.
