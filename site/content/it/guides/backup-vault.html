Il tuo archivio è un solo file .kdbx. Esportane una copia di tanto in tanto e tienila da un’altra parte: se perdi il dispositivo, quella copia è il tuo archivio.

Tutte le piattaforme3 minuti

Esportare una copia

  1. Apri Settings e scegli Backups & import

    Con l’archivio sbloccato. Lo trovi nel gruppo Database.

  2. Scegli Export the database

    Il sistema ti chiede dove salvare il file. Scegli se puoi un posto fuori dal dispositivo, per esempio una chiavetta USB.

  3. Aspetta la conferma

    Custode mostra Database backup exported. La copia è lo stesso file cifrato: si apre con la password principale che l’archivio aveva nel momento in cui l’hai esportato.

  4. Se usi un file chiave, esporta anche quello

    Scegli Export the key file. Senza il file chiave la copia dell’archivio non si può aprire. Come dice l’app, tienilo separato dal database: non nello stesso posto della copia dell’archivio.

Ripristinare una copia

  1. Vai all’elenco degli archivi

    È la prima schermata dell’app. Se un archivio è aperto, vai in Settings e scegli il pulsante Close database accanto al titolo Database. L’app ti chiede conferma e avvisa che le credenziali salvate per quell’archivio su questo dispositivo vengono rimosse: tieni a portata di mano la password principale.

  2. Scegli Open existing database

    Scegli la copia .kdbx che hai esportato.

  3. Sbloccala

    Inserisci la password principale e, se l’archivio ne aveva uno, scegli il file chiave con Use a key file.

Su telefono o tablet

L’app tiene una propria copia del file che apri. Se c’è già un archivio con lo stesso nome di file, Custode chiede Replace existing database?: con Replace quello nell’app viene sovrascritto dalla copia che stai aprendo.

Sul telefono l’archivio vive dentro l’app. Se elimini Custode senza una copia di sicurezza, il file se ne va con lei. Esporta una copia prima di disinstallare l’app o di cambiare telefono.
