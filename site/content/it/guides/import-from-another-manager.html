Porta le tue password in Custode da un file CSV esportato da Bitwarden, LastPass o Chrome, oppure apri un archivio KeePass .kdbx che hai già.

Tutte le piattaforme10 minuti

Prima di iniziare

L’importazione da CSV funziona dentro un archivio già aperto, quindi creane o aprine uno prima. Poi esporta le password dall’altra app come file CSV, con la sua opzione di esportazione, e tieni il file sul dispositivo dove funziona Custode.

Importare un file CSV

  1. Apri l’importazione

    Sblocca l’archivio, apri Settings, poi Backups & import e scegli Import from CSV. Seleziona il file .csv nel selettore di file.

  2. Controlla l’anteprima

    La schermata Import CSV mostra il file, il Detected format (Bitwarden, LastPass, Chrome, 1Password, Apple Passwords o Generic CSV) e tre conteggi: Rows found, Valid records e Skipped rows.

  3. Decidi sui duplicati

    Avoid duplicates è attivo di default: salta le righe che corrispondono a una voce già presente nell’archivio, confrontando titolo, nome utente e URL. Spegnilo solo se vuoi aggiungere ogni riga.

  4. Importa

    Scegli Import seguito dal numero di voci valide, oppure Cancel per fermarti senza cambiare nulla.

  5. Leggi il risultato

    Import finished ti dice quante voci sono state aggiunte e quante saltate perché duplicate. Le righe che non si sono potute leggere sono elencate con il motivo. Scegli Done per chiudere.

Cosa viene importato

Titolo, nome utente, password, URL, note
Letti dalle colonne del file, qualunque sia il formato noto da cui arriva.
Codici monouso
Una colonna con un link otpauth:// viene conservata come campo di nome otp nella voce.
Altre colonne
Ogni altra colonna con un valore viene conservata come campo personalizzato con il nome della colonna. Le cartelle non vengono ricreate: una colonna cartella è conservata allo stesso modo, come campo.
Non importati
Le colonne type, favorite, fav e reprompt, le righe senza nulla in titolo, nome utente, password, URL e note, e ogni colonna di passkey: una passkey si crea nell’app, sul sito che la richiede. La schermata del risultato li elenca.

Elimina il CSV al termine. Contiene le tue password in chiaro, come Custode ti ricorda nella schermata di anteprima. Svuota anche il cestino e rimuovilo dai download dell’altra app.

Aprire un archivio KeePass

Un file .kdbx di KeePass o di un’altra app compatibile non va importato: è già nel formato usato da Custode. Scegli Open existing database e seleziona il file, poi sbloccalo con la sua password principale o il suo file chiave. I passaggi sono in Creare il primo archivio.

Aprire un .kdbx lo aggiunge a Custode come archivio separato. L’app non ha un’opzione per unire un archivio a un altro: per spostare voci tra due archivi serve un CSV.
