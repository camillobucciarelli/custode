Ogni volta che apri un archivio, Custode ti chiede di sbloccarlo. Puoi scrivere la password principale, usare un file chiave, oppure lasciare che sia la tua impronta o il tuo volto a farlo.

Tutte le piattaforme3 minuti

Prima di iniziare

Le credenziali accettate da un archivio sono quelle scelte quando è stato creato o cambiate poi in Settings: una password principale, un file chiave, oppure entrambi. Per la biometria il dispositivo deve avere lo sblocco con impronta o volto configurato.

Sbloccare con la password principale

  1. Scrivi la password

    Nella schermata di sblocco, che mostra il nome dell’archivio, scrivila in Master password. L’icona a forma di occhio (Show password) ti permette di controllare cosa hai scritto.

  2. Sblocca

    Scegli Unlock vault. Mentre lavora Custode mostra Decrypting e il nome dell’archivio: può volerci un momento.

Se la password o il file chiave sono sbagliati, il campo mostra Incorrect master password or key file. e puoi riprovare.

Sbloccare con un file chiave

  1. Scegli Use a key file

    È il link sotto il pulsante di sblocco. Se il dispositivo ha un blocco schermo, Custode ti chiede prima di autenticarti: protegge i file chiave conservati nell’app.

  2. Importa o scegli il file chiave

    L’elenco Internal key files mostra i file chiave conservati nell’app. Se il tuo non c’è, scegli Import e seleziona il file dal dispositivo, poi scegli Select accanto ad esso.

  3. Sblocca

    Il file scelto compare sotto il campo della password, con Remove key file per toglierlo. Il pulsante ora dice Unlock with key file. Se l’archivio usa solo il file chiave, lascia vuota la password: è Optional while a key file is selected. Se usa entrambi, scrivi anche la password.

Custode ricorda quale file chiave usa un archivio. Se il file non c’è più, dice Key file not found. Locate or select the required key file. e puoi sceglierlo di nuovo.

Sbloccare con la biometria

  1. Attivala

    Quando crei un archivio, usa l’interruttore Enable biometric protection. Per un archivio che già usi, sbloccalo, apri Settings e attiva Biometric protection. Richiede una password principale, che Custode conserva a questo scopo nell’archiviazione sicura del dispositivo.

  2. Autenticati

    La volta successiva che apri l’archivio Custode mostra Authenticate with biometrics e chiede impronta o volto. Se funziona, l’archivio si apre da solo.

  3. Se non funziona

    Scegli Retry per riprovare, oppure Use master password instead per scrivere la password questa volta. La biometria sarà richiesta di nuovo alla prossima apertura dell’archivio.

Per disattivarla, spegni Biometric protection in Settings: la password conservata viene cancellata dal dispositivo. Se la biometria non è disponibile sul dispositivo, Custode dice Biometric authentication is not available on this device. e mostra il modulo normale.

Nessun recupero. Custode non ha un account né un’opzione “password dimenticata”. Senza la password principale, o il file chiave, l’archivio non si apre, e un file chiave generato non si recupera se lo perdi. Tieni al sicuro entrambi ed esporta il file chiave separatamente dal database: in Settings, Backups & import, Export the key file.
