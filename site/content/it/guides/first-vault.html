Un archivio è un unico file .kdbx che contiene tutte le tue password, protetto da una password principale, da un file chiave o da entrambi. Puoi crearne uno nuovo o aprire un file KeePass che hai già.

Tutte le piattaforme5 minuti

Prima di iniziare

Custode deve essere installata. Per aprire un archivio esistente ti servono il suo file .kdbx sul dispositivo e la sua password principale o il suo file chiave.

Creare un archivio nuovo

Al primo avvio la schermata di benvenuto mostra Create new database. Se hai già un archivio, la stessa azione è nell’elenco Databases, tra le opzioni per aggiungerne uno.

  1. Dai un nome al file

    Sotto Name your database (Step 1 of 2) scrivi il nome in Database file name. I caratteri \ / : * ? " < > | non sono ammessi. Poi scegli Continue.

  2. Scegli come proteggerlo

    Sotto Choose your credentials (Step 2 of 2) puoi usare una password principale, un file chiave o entrambi. Ne serve almeno uno: finché non lo imposti, la schermata te lo dice e Create resta disattivato.

  3. Imposta una password principale

    Scrivila in Master Password (optional). Un indicatore di robustezza mostra Weak, Fair, Good o Strong, e un secondo campo, Confirm Password, ti chiede di scriverla di nuovo.

  4. Aggiungi un file chiave, se vuoi

    Sotto Key File scegli un’opzione: No key file, Select an existing file per usare un file che hai già, oppure Generate automatically per farne creare uno a Custode.

  5. Decidi sulla biometria

    L’interruttore Enable biometric protection è spento di default. Accendilo se vuoi sbloccare con impronta o volto. Richiede una password principale: senza, Custode ti chiede di impostarne una o di spegnere l’interruttore. Altro in Sbloccare con biometria o file chiave.

  6. Crea l’archivio

    Scegli Create. Custode mostra poi la schermata di sblocco del nuovo archivio: inserisci le tue credenziali per aprirlo.

Conserva una copia del file chiave. Se lo generi, Custode ti avvisa: perdere il file chiave rende il database inaccessibile. L’archivio è salvato nello spazio riservato all’app, quindi esporta ogni tanto una copia di sicurezza: se elimini Custode senza, il file se ne va con lei. Trovi le esportazioni in Settings, sotto Backups & import: Export the database e Export the key file.

Aprire un archivio che hai già

  1. Scegli Open existing database

    Si trova nella schermata di benvenuto o nell’elenco Databases. Il selettore di file mostra solo i file .kdbx: scegli il tuo.

  2. Sbloccalo

    Custode tiene una sua copia del file nello spazio dell’app e apre la schermata di sblocco. Inserisci la password principale, oppure scegli Use a key file se l’archivio ne ha uno.

Alcuni messaggi che potresti vedere:

Replace existing database?
Nell’app c’è già un database con quel nome. Replace lo sovrascrive con il file scelto, altrimenti annulla.
Duplicate database detected
Hai scelto un file che corrisponde a uno già presente nell’app. Scegli Keep both per salvarlo come altro database, Replace existing per fare una copia di sicurezza e sostituire quello vecchio, oppure Use existing per aprire quello che hai.
Invalid database file
Il file non è un database Custode valido. Controlla di aver scelto il .kdbx giusto.
Database file is corrupted
Il file non si può leggere e potrebbe essere danneggiato. Prova con una copia di sicurezza.

Un archivio su Google Drive

Se l’archivio è su Google Drive, scegli invece Open from Google Drive, accedi e scegli il file. Custode ti propone poi di richiedere l’autenticazione biometrica per quell’archivio. Per tenerlo allineato tra i dispositivi, vedi Sincronizzare con Google Drive.
