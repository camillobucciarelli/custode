Download Custode

Custode is an open source password manager. It keeps your vault in the KeePass .kdbx format, on your own devices.

Version __VERSION__

Android (APK) Windows (ZIP) Linux (ZIP)

How to install

  • Android: open the APK and allow your browser to install apps when Android asks.
  • Windows: extract the ZIP and run password_manager.exe from the extracted folder.
  • Linux: extract the ZIP and run password_manager from the extracted folder.
  • iOS and macOS: distributed through TestFlight.
  • Browser extension: Custode on the Chrome Web Store.
